# JCI Drones Website

> A fictional drone company site, designed in Figma and built as working code.

## Overview

- Individual Human Computer Interaction lab project: designed a drone company website in Figma, then hand-coded it in plain HTML, CSS and JavaScript.
- I deliberately diverged from the prototype where real interactivity demanded it.

## Data / Scope

- Scope: Home, Products, Store, Forum and Contact Us pages, following HCI principles like consistency and clear navigation.

## Workflow

- Prototyped the five-page site in Figma with a consistent palette, typography and layout.
- Added a working product filter, live like-counts and full JavaScript form validation written without regex.
- Built it mobile-responsive from scratch with media queries, CSS Grid and Flexbox.

## Results

- Contact form with 6 fields and real-time validation written in plain JavaScript.
- Working filters and like counter that Figma could not provide.
- Fully responsive layout across screen sizes.

## Tech Stack

Figma, HTML, CSS, JavaScript, Responsive design

## Repository Structure

```
index.html  products.html  store.html  forum.html  contactUs.html   Five pages
css/style.css                                                        Layout, responsive rules
js/script.js                                                         Filter, like counter, form validation
img/                                                                 Images and icons
docs/                                                                HCI lab documentation (PDF)
```

## How to Run

Open `index.html` in a browser, or serve the folder with `python -m http.server`. No build step is needed.
